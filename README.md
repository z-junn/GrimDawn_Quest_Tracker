# 黎明助手 / Grim Dawn Assistant

GDA 整合《Grim Dawn》的任務追蹤、掉落篩選與地圖 Overlay，提供中文／英文介面。

## v0.4

- 「始終顯示獨特物品」：史詩、傳說無條件顯示，其餘裝備依設定的詞條組合篩選。
- 自訂 Overlay 快捷鍵，預設 M。
- 篩選只保留目前介面，移除新舊版本切換。
- 修正中英文名稱、設定文字及新舊 EXE 檔名的更新安裝相容性。

一般使用者選擇 **GrimDawn_Assistant_v0.4_Win64.zip**，完整解壓並執行 **GrimDawnAssistant.exe**。更新時保留原本的 **Data**、**Backups**，並重新啟動 Grim Dawn 一次。

舊 QT 的程式內更新資產仍為 **GrimDawnQuestTracker.exe**，內容與新名稱 EXE 相同。本版支援新舊檔名的後續更新。先前 v0.4 測試包與本版版本號相同，請手動替換 EXE 一次，保留 Data 與 Backups。

完整原始碼請下載明確命名的 **GrimDawn_Assistant_v0.4_Source.zip**。此儲存庫主要提供版本下載；GitHub 自動的 Source code ZIP 不代表完整程式來源。

GDA provides quest tracking, loot filtering and an in-game map overlay with Chinese and English UI. Download the full Windows ZIP, keep Data and Backups when upgrading, and restart Grim Dawn once. The explicit Source ZIP contains the complete project. Legacy-named updater assets remain available for existing QT clients.
