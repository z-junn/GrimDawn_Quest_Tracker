# 黎明助手 · Grim Dawn Assistant

GDA 是 Grim Dawn Windows x64 助手，整合任務紀錄、掉落篩選與地圖 Overlay。

## v0.4 下載

[下載 Windows x64 完整包](https://github.com/z-junn/GrimDawn_Quest_Tracker/releases/download/v0.4.0/GrimDawn_Assistant_v0.4_Win64.zip)

[查看 v0.4 發佈內容與所有檔案](https://github.com/z-junn/GrimDawn_Quest_Tracker/releases/tag/v0.4.0)

完整解壓縮後執行 **GrimDawnAssistant.exe**。一般使用者不需要 GitHub 帳號。

## 更新重點

- 新名稱 GDA，採用黑金日出圖示，A 疊在 GD 中央前方。
- iOS 風格介面：任務總覽、掉落篩選、地圖 Overlay 與底部齒輪設定。
- 更新檢查、版本下載與更新操作移至 **設定 → 程式更新**。
- 語言上方僅保留目前版本與「最新／待更新」。
- 保留十類新版掉落篩選、v0.3.22 舊版編輯器，以及既有資料格式。

## 保留個人資料

升級前先關閉舊程式，保留原資料夾內的 **Data** 與 **Backups**。個人進度與設定儲存在各自電腦，不會上傳到 GitHub。

介面顯示 **v0.4**；更新相容標籤為 **v0.4.0**。發佈中的 **GrimDawnQuestTracker.exe** 是舊版自動更新使用的相容檔，與新名稱執行檔內容一致。
