# GDA v0.4.12：盾牌與副手前後綴

掉落篩選 → 篩選類型「前後綴」→「飾品&副手」新增盾牌與副手法器，保留戒指、項鍊、勳章。類別內部 ID 仍為 jewelry；既有裝備、詞綴與具名存檔的穩定 ID 保持不變。

新增兩個獨立適用性分組，不將單手武器或飾品的詞綴清單直接套到盾牌／法器。盾牌包含 45 個前綴、50 個後綴名稱與品質組合；副手法器包含 21 個前綴、43 個後綴名稱與品質組合。等級版本、效果、職業分組、品質顏色及簡繁中文／英文搜尋沿用既有介面。保留未選擇部位時不得勾選詞綴的行為。

資料沿用已核查的官方 ARZ、GrimTools 1.3.1.0 適用性及 GD Stash 對照。新群組各含 621／412 個本機定義；其中 13／4 個定義尚無已確認的一般掉落正權重路徑，可能與其他分組共用。因此不宣稱列出每個版本都正常掉落。名稱逐筆依官方中英文 lootRandomizerName tag 對照。

遊戲端辨識表同步新增全部盾牌與法器底材記錄，重新建置原生篩選 DLL；數值讀取位置與通訊格式沒有改動。更新後請退出並重開 Grim Dawn，再啟動 GDA，以載入新版 DLL。

v0.4.12 同時包含先前本機修正：Filter 跟隨介面大小與文字大小設定。任務、地圖 Overlay、GPS 與設定檔格式保持不變。更新交接使用隔離程式與獨立 Data，確認原有篩選存檔、具名組合、Overlay 偏好設定保留。原生測試只在測試程序內驗證，不連接玩家遊戲。

長詞綴說明依滑鼠所在詞綴上下方的實際空間定位，空間不足時只讓說明內容捲動，避免遮住原本的勾選框；頁面捲動時同步更新位置。
